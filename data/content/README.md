# Digital Textbook Content Directory

This directory contains standalone HTML files for each section of the digital physics textbook.

Whenever you want to update the layout or text displayed in a sidebar tab, you can edit these files directly. The textbook dynamically loads them at runtime.

## 🛠 How to Edit

1. **Open the File**: Double-click any of the links below or open the relevant file in your editor (e.g., VS Code).
2. **Use Normal HTML Quotes**: You don't need to escape double quotes (`"`) like in JSON files.
3. **Use Normal LaTeX Math**: Write equations using normal MathJax formatting:
   - Inline math: `$ \theta $`
   - Block equations: `$$ s = ut + \frac{1}{2}at^2 $$`
4. **Save File**: The changes will instantly appear on your local website.
